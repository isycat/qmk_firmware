# AJAZZ / EPOMAKER AK820 Pro – isycat VIA keymap

Port of the Drop CTRL v1 isycat keymap (`massdrop/ctrl/keymaps/isycat` on the `ctrl-v1-via`
branch) to the AK820 Pro. The board support code (LCD, Bluetooth/2.4G, RGB driver, knob, clock)
is fpb's community port (branch `ak820pro-lcd-flash` of github.com/fpb/qmk_firmware, QMK ~0.31).
This keymap only adds the keymap logic. Build it separately from the CTRL, which stays on 0.26.11.

    # once: apply the six ChibiOS patches listed in keyboards/a_jazz/ak820pro/readme.md
    make a_jazz/ak820pro:isycat                  # LCD panel v1 (default)
    make a_jazz/ak820pro:isycat -e LCD_PANEL=v2  # LCD panel v2 (upside-down/odd colours on v1)

## What it does

Same features as the CTRL keymap:

| Input | Output |
|---|---|
| Ctrl + PgUp / PgDn | Ctrl + Home / End |
| Ctrl + [Shift] + Left / Right | [Shift] + Home / End |
| Alt + [Shift] + Left / Right | Ctrl + [Shift] + Left / Right (word jump) |
| Ctrl + Alt + Left / Right | Ctrl + Shift + Tab / Ctrl + Tab |
| Knob press (`PP_TD`), 1 tap / 2 taps | Play/Pause / Next track |
| AltGr SE (Right Alt) + a or [ / o or ; / e or ' | å / ö / ä (Shift: capital) |
| F1 outside game mode | Alt+F23 (set in VIA) |
| Win key (`TH 1`) | hold: Win, tap: Alt+F23 |
| Caps Lock | F24 (for AHK) |

The nav remaps tap F22 before hiding Alt, so Windows never sees a lone Alt. Game mode follows the
host's Num Lock (AHK sets it in fullscreen apps) and Fn+G toggles it.

### Keys this board doesn't have

The AK820 Pro is a 75% board without Pause, Scroll Lock, Print Screen, Insert or End keys. The
default Fn layer adds them:

| Key | Fn + key |
|---|---|
| Del | Scroll Lock |
| Backspace | Insert |
| PgUp | Print Screen |
| PgDn | End |
| G | Game mode |
| N | NKRO on/off |
| Enter | LCD animation on/off (was Fn+Del) |
| Knob press | Mute |

Everything else on the Fn layer is fpb's: Fn+Esc bootloader, Fn+F1..F12 media, Fn+Q/W/E Bluetooth
slots, Fn+R 2.4G, Fn+P pair, Fn+Home screen on/off, Fn+X lights on/off, Fn+arrows hue/brightness.

## Lighting

* **Scroll Lock light**: whichever key has Scroll Lock in the Windows base layer lights up (red by
  default) while Scroll Lock is on. If the base layer has none, the key that has it in the Fn layer
  lights up, which by default is **Del**. Move Scroll Lock in VIA and the light moves too
  (within a second).
* **Game mode light**: the key(s) with F1 in the base layer.
* Lights on/off (`LED Zone`, Fn+X, the VIA "Lights" setting, or VIA effect "All Off") blanks the
  keys but keeps the matrix running, so both lights still work with the lights "off".
* Per-key paint and the 15-colour palette work as on the CTRL. There's no underglow on this board,
  so the CTRL's underglow settings are left out.
* **Sleep**: fpb's port blanks the lights and screen after 3 idle minutes. Here the time is set in
  VIA (0 = never), and by default the board stays awake while Scroll Lock is on, so the mic-muted
  light never goes dark during a call.

## VIA

Load `via/ak820_pro_isycat.json` in VIA (Settings, "Show Design tab", then Design, "Load Draft
Definition"). It is generated by `tools/gen_via_definition.py` from the board's own `via.json` and
keeps fpb's custom keycodes (Bluetooth, RGB, LCD) in front of these: `PP_TD`, `AltGr SE`, `LED Zone`,
`TH 1-4` and `Game`. The menu value ids match the CTRL keymap's, plus 68/69 for the sleep settings.

## Board-specific notes

* EEPROM is emulated in the MCU's flash, and a flash write stalls the CPU. Settings are saved half a
  second after the last change, and never while the screen is being drawn.
* The emulated EEPROM is 2 KB (the board default of 1 KB is too small for 4 VIA layers).
* Every flash writes the whole 256 KB image, so it resets VIA's keymap and these settings.
* The only change outside this folder is a weak `display_sleep_timeout_ms()` hook in
  `ak820pro.c`, so the keymap can set the sleep time.
