# GMMK Pro – isycat VIA keymap

Port of the Drop CTRL v1 isycat keymap (`keyboards/massdrop/ctrl/keymaps/isycat`) to the original
Glorious GMMK Pro (75%). Not for the GMMK 3 Pro, which does not run QMK.

One keymap builds for all four board variants:

    make gmmk/pro/rev1/ansi:isycat   # STM32F303, bootloader shows as "STM32 BOOTLOADER" (0483:DF11)
    make gmmk/pro/rev1/iso:isycat
    make gmmk/pro/rev2/ansi:isycat   # WestBerry WB32F3G71, bootloader 342D:DFA0
    make gmmk/pro/rev2/iso:isycat

The built-in keymap is written against the raw 11x8 matrix (`layers.h`, generated by
`tools/gen_layers.py`), which is the same on ANSI and ISO boards, and every LED position comes
from `g_led_config`, so there is no per-variant code.

## Flashing

Unplug, hold Esc, plug in (this also clears saved settings), then flash the `.bin` for your variant
with QMK Toolbox. Fn+\ also enters the bootloader once this firmware is on. If neither works, the
PCB has a reset button under the plate. Glorious publishes the stock CORE firmware if you want to go back.

## What it does

Same as the CTRL keymap: the navigation remaps (Ctrl+PgUp/PgDn, Ctrl/Alt+[Shift]+Left/Right,
Ctrl+Alt+Left/Right), `AltGr SE` Swedish letters via Windows Alt codes, the `PP_TD` Play/Next key,
Tap/Hold keys TH 1-4, lighting zones, per-key paint and palette, all switchable from VIA.

Differences from the CTRL version:

* "Underglow" is the two side light bars (`LED_FLAG_UNDERGLOW`). The rainbow mode runs down the bars.
* The GMMK Pro has no Scroll Lock key, so the indicator lights whichever key has `KC_SCRL` on the
  base layer (rescanned twice a second, so it follows VIA edits). With no such key, or when set to,
  the side bars show it. Default: Fn+PrtSc is Scroll Lock, so the side bars light up.
* Custom keycodes start at `QK_KB_0` with `PP_TD`; there are no Drop-specific keys.
* The knob is in VIA's keymap (volume on the base layer, previous/next track on Fn). Knob press is Mute,
  Fn+knob press is `PP_TD`.

Default layer differences from Glorious' default: Caps Lock is F24, left Win is TH 1 (hold Win, tap
Alt+F23), Right Alt is `AltGr SE`. Fn layer: PrtSc = Scroll Lock, Del = Insert, PgUp = Home,
\ = bootloader, Q-T / A-G = lighting (as on the CTRL), Z = cycle zones, N = NKRO toggle.

## VIA

Load `via/gmmk_pro_isycat.json` (generated by `tools/gen_via_definition.py` from
the-via/keyboards `v3/gmmk/pro/gmmk_pro.json`) in VIA under Settings, "Show Design tab", then Design,
"Load Draft Definition". For an ISO board, turn on the "ISO Enter" and "Split Left Shift" layout options.
